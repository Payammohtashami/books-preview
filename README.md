# کتاب درسی تعاملی سه‌بعدی

اپ PWA آفلاین برای نمایش کتاب‌های درسی با بخش‌های سه‌بعدی و تعاملی. سند کامل: [`docs/PROJECT.md`](docs/PROJECT.md)

## اجرا

```bash
npm install
npm run dev        # توسعه
npm run build      # ساخت نسخه‌ی نهایی (با Service Worker)
npm run preview    # آزمایش نسخه‌ی ساخته‌شده و حالت آفلاین
```

> آزمایش آفلاین فقط روی `npm run preview` (یا نسخه‌ی منتشرشده) درست کار می‌کند، نه `npm run dev`.

## وضعیت

- مرحله‌ی ۱: اسکلت (Vite + React + TS، RTL فارسی، تم، PWA آفلاین).
- پیش‌درآمد و صفحه‌ی کتاب با فهرست فصل‌ها.
- **حالت «کتاب»**: خواننده‌ی PDF (pdf.js) با ناوبری، زوم، پرش به فصل و ذخیره‌ی آخرین صفحه.
- **حالت «درس تعاملی»** (فعلاً فصل ۳ علوم هشتم): متن و تصویرهای کتاب با ظاهر بهتر، مدل سه‌بعدی بور (اتم، ایزوتوپ، یون)، پاسخ پیشنهادی فعالیت‌ها و خودآزمایی.

## افزودن درس تعاملی برای فصل دیگر
1. فایل `public/content/<کتاب>/lesson-N/lesson.json` و پوشه‌ی `images/` کنار آن بسازید (ساختار: `src/lib/lesson.ts`).
2. در `book.json` برای همان فصل `"lesson": "lesson-N/lesson.json"` اضافه کنید.

> بعد از اولین باز کردن هر کتاب در حالت «کتاب» (آنلاین)، فایل PDF برای استفاده‌ی آفلاین کش می‌شود.

> فایل کتاب عمداً با پسوند `.txt` (مثلاً `book.txt`) ذخیره می‌شود تا افزونه‌های مدیریت دانلود (مثل IDM) آن را قاپ نزنند؛ محتوایش همان PDF است.
